🎨 VISUAL DESIGN SYSTEM

COLOR SYSTEM:
- Base: Deep navy (#0B0F1A), black gradient
- Primary accent: Cyan-blue gradient (#00D4FF → #4A6CFF)
- Secondary accent: Purple (#7C5CFF)
- Highlight: Neon teal glow

BACKGROUND:
- Animated gradient mesh
- Floating crypto icons (Bitcoin-style coins, tokens)
- Soft glowing particles
- Subtle network lines (AI intelligence feel)

CARDS:
- Glassmorphism:
  - blur: 20–30px
  - opacity: 10–20%
  - soft border (1px gradient)
- Rounded corners (16–24px)
- Inner shadow for depth

TYPOGRAPHY:
- Headings: Bold, large, modern sans-serif
- Body: Clean, readable
- Avoid heavy Web3 fonts

SPACING:
- Extremely clean
- Large padding
- Avoid clutter
